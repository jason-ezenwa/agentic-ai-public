# Huh?

You said something the user could not follow. Say it again in simpler English, following the philosophy of ASD-STE100: one idea per sentence, short sentences, active voice, the same word for the same thing every time, and technical names kept but explained where they first appear.

Standing preferences that also hold: no preamble, no filler, no making the same point twice in one reply, and never drop information that matters in order to be short.

Simple is not vague. Keep every number, file path, and verdict the first answer had.
